Hardpoint STL

A hardpoint STL is an ordinary binary STL that also remembers which CAD face every triangle came from (flat, cylinder, sphere, cone, torus, freeform) and where the face corners are. The labels live in bytes every STL already has, so slicers and viewers open it as a normal mesh, while Twoo STEP CAD Toolbox can skip guessing and rebuild each face as the surface it really was. The FreeCAD and Fusion plugins write them (Export hardpoint STL), and this tab can make one from any plain STL. Format: HARDPOINT_STL.md.

What to do with it

A hardpoint STL carries its own units; the setting above only applies to plain STLs. Each labelled face is checked against the tolerance before it is trusted; a face that does not fit its label goes through the normal detection instead.

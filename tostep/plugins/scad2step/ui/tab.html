OpenSCAD model

Rebuilds an OpenSCAD model as real CAD geometry (true cylinders, cones, spheres, arcs, swept surfaces and exact booleans), instead of exporting a mesh and guessing at it afterwards. Needs OpenSCAD installed, except for .csg files. Engine: SCAD2STEP.

Or drop a .scad / .csg here (a dropped file has no libraries beside it and no live link)

Parameters

The model's own Customizer variables. Change them to export a variant without editing the file. Applies to Convert, not to the live link.

Options

No file chosen

Live link on. Save in OpenSCAD (F2) and is rebuilt within a second or two.

Use Twoo STEP CAD Toolbox inside your CAD program

This app works on its own. These buttons also put its plugin into your CAD program, set up to use this folder. Re-install after moving the folder or updating.

Every FreeCAD found (normal, AppImage, Flatpak, Snap). Then restart FreeCAD and choose the Twoo STEP CAD Toolbox workbench.
macOS / Windows. Then restart Fusion — buttons under Utilities → Add-Ins.
Linux: start it like any other app.
Linux Mint (Nemo), GNOME Files, Windows Send to: Convert to STEP for a mesh or an OpenSCAD model, and Live-link for a .scad.
